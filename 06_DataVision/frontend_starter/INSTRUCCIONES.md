# Integración del frontend
1. Crear proyecto Ionic Angular con `INICIAR_PROYECTO.ps1` o comandos manuales.
2. Copiar `api.service.ts` dentro de `src/app/services/` y adaptar importaciones.
3. Implementar vistas respetando `ENUNCIADO.md`.
4. En configuración de la app, solicitar URL de backend, ejemplo `http://192.168.1.151:80/fotometa/api`.
5. Probar `GET health.php` antes de desarrollar las demás pantallas.
6. El frontend aquí es un **starter**, no una aplicación ya implementada.
